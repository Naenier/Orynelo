# Changelog

All notable changes to OpsDoctor are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Release Please updates versioned sections from Conventional Commits.

## [Unreleased]

### Added

- Shared, cancellable diagnostics for target parsing, proxy selection, DNS,
  route and source discovery, TCP, TLS, HTTP, redirects, and timing evidence.
- Evidence-based summaries and redacted text, JSON, and Markdown reports.
- Cobra CLI with diagnosis, completion, stable exit codes, and build metadata.
- Fyne desktop application with progress, result details, history, saved
  profiles, settings, export, keyboard shortcuts, and About information.
- Private YAML configuration, SQLite history and profiles, migrations, and
  retention controls.
- Linux, macOS, and Windows build jobs; native desktop archives; CLI release
  archives; SHA-256 checksums; and Release Please automation.
- Non-root, distroless CLI container image and GHCR release publishing.
- Unit, race, offline integration, lint, vulnerability, workflow/YAML,
  versioning, and container validation in CI.
- Architecture, diagnostic model, security, versioning, contribution, and
  Kubernetes roadmap documentation.
